# 👨🏻‍💻 Vinícius Lemes dos Santos

**`Desenvolvedor Full Stack | Data Analysis`**

Me chamo Vinícius Lemes dos Santos, tenho 27 anos e sou de Jacareí, SP. Atualmente, estou no 4º semestre de Desenvolvimento de Software Multiplataforma na FATEC. Minha trajetória anterior em logística e gestão de tráfego me deu uma base sólida em estratégia e resolução de problemas, que hoje aplico no desenvolvimento de software.

Atualmente, trabalho com análise de dados e automação industrial, trazendo uma forte visão analítica para a tecnologia. Meu foco principal de desenvolvimento abrange o ecossistema **JavaScript/TypeScript (Node.js e React)**, conteinerização com **Docker** e bancos de dados relacionais (**PostgreSQL**). 

Gosto de construir soluções que unem software e hardware para gerar impacto real. Entre as minhas construções estão o **NexDose**, uma solução health-tech IoT integrando ESP32 e React Native, e o **SkyHawk**, uma aplicação web desenvolvida para a visualização de dados ambientais do programa Queimadas do INPE. Além da tecnologia, dedico tempo ao aprimoramento contínuo do meu inglês voltado para comunicação profissional.

🚀 **Objetivo:** Busco minha primeira oportunidade como Desenvolvedor Júnior, onde eu possa agregar valor unindo minha criatividade, lógica e visão de dados na construção de sistemas eficientes e inovadores.
